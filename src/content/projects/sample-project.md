## 프로젝트 개요

## 선정 이유와 목표

만든 이유와 확인하려던 목표를 작성합니다.

## 나의 참여 범위

팀 전체의 결과와 구분해 직접 수행한 작업, 수정한 코드, 검증한 내용을 작성합니다.

## 시스템 구성

전체 시스템과 데이터 흐름을 설명합니다. 이 섹션에 실제 구성에 맞는 SVG나 이미지를 추가합니다.

## 주요 구현

주요 구현과 코드 위치를 설명합니다. 긴 개발 로그는 Blog로 분리할 수 있습니다.

## 문제 해결 기록

### 문제 제목

- **Problem:** 관찰한 현상과 재현 조건
- **Investigation:** 확인한 로그, 코드, 배선, 환경
- **Hypothesis:** 의심한 원인과 근거. 확인된 사실과 구분
- **Attempt:** 변경하거나 시험한 내용
- **Result:** 변경 전후에 관찰한 결과
- **Remaining Questions:** 확인하지 못한 원인 또는 후속 검증

## 결과와 확인 자료

실제 사진, 실행 출력, 테스트 결과 또는 동영상 링크를 근거로 작성합니다.
자료가 없다면 성능 수치나 성공 결과를 만들어 쓰지 않습니다.
